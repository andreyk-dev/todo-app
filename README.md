# To-Do & Categories API

Бэкенд-сервис для управления задачами и категориями, построенный на FastAPI с использованием трёхслойной архитектуры и базы данных PostgreSQL.

## Стек технологий
* **Python 3.12+**
* **FastAPI** — веб-фреймворк для создания REST API
* **PostgreSQL** — реляционная база данных (развернута в Docker)
* **SQLAlchemy 2.0** — ORM для взаимодействия с БД
* **Pydantic v2** — валидация входных и выходных данных

## Архитектура проекта
Проект разделен на независимые слои ответственности:
* `routers/` — слой API (прием HTTP-запросов, маршрутизация)
* `services/` — слой бизнес-логики и управление транзакциями
* `repositories/` — слой прямого доступа к данным (SQLAlchemy)
* `schemas/` — DTO-модели валидации и сериализации (Pydantic)
* `models/` — декларативные таблицы базы данных

## Реализованный функционал
- [x] Настройка подключения к PostgreSQL в Docker (`pg-container`)
- [x] Модуль задач (`/tasks`): получение, создание, частичное обновление, удаление
